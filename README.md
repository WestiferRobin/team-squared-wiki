# Team Squared

Documentation repository for the Team Squared CS 514 database product project.

## Project Repositories

- `team-squared-app` — React/Next.js frontend
- `team-squared-service` — .NET backend, relational database integration, migrations, seed data, and tests
- `team-squared-dev` — local development and integration orchestration
- `RoadToTheFinal` — legacy Flask/Python reference implementation

## Documentation Responsibilities

This repository will contain:

- Product overview and requirements
- User stories
- Architecture documentation
- Database design and ER diagram
- Setup and usage documentation
- Project phase plans
- Team roles and contribution tracking
- AI-assistance disclosure
- Blog material
- Technical report material
- Presentation material

## Migration Strategy

`RoadToTheFinal` remains preserved as the legacy reference implementation while functionality is migrated into the new frontend and backend architecture.

Legacy functionality should only be retired after its replacement has been implemented and verified.
